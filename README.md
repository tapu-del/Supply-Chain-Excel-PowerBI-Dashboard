# Supply Chain Dashboard — Excel + Power BI

## Project Overview
Analyzed supply chain data (100 SKUs) to identify revenue patterns, product performance, supplier efficiency, and regional trends.

## Tools Used
- Microsoft Excel (Data Cleaning, Pivot Tables)
- Power BI (Dashboard, Charts, Slicers)

## Key Insights

1. **Total Revenue:** 577.60K
2. **Total Products Sold:** 46K units
3. **Average Price:** 4.95K
4. **Average Defect Rate:** 227.72 (high — needs quality check)

### Product Type Performance
- **Skincare** generates the highest revenue (approx 240K)
- **Haircare** is second (approx 174K)
- **Cosmetics** is third (approx 161K)
- **Skincare** has the highest units sold (21K, 44.97%)

### Supplier Performance
- **Supplier 4** has the highest revenue (approx 240K)
- **Supplier 1** is lowest
- Supplier performance varies significantly

### Location Trends
- **Mumbai** has the highest revenue (140K)
- **Delhi** has the lowest
- Revenue drops sharply after Mumbai
